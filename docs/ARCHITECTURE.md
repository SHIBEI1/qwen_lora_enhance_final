# 终版模型架构

Qwen-Image-Edit-2511 是唯一基础图像模型。训练输入为低质量图、固定内部提示词和配对高质量目标；通过冻结的 VAE 与 Qwen2.5-VL 编码器提供条件，只更新 DiT 的 LoRA 参数。基础模型权重与编码器不训练。

LoRA 配置为 rank 16、alpha 32、dropout 0.05。正式训练运行了 6 轮，终版固定第 3 轮 / step 1920 适配器。发布权重路径和 SHA-256 见 `release.json`。

推理流程：输入图像 → 固定文本及图像条件编码 → Qwen DiT + epoch-03 LoRA 迭代生成 → VAE 解码 → 调整回输入图像尺寸。用户只提交图像，不提交提示词。

提示词表达保持内容、自然亮度、清晰度与真实纹理的目标；它不保证每个像素或细节与目标图完全一致。此次小样本实验中，低光质量有改善，GoPro 配对 PSNR/SSIM 并未达到专用去模糊复原模型的水平。

Musubi Tuner 为固定到 `v0.2.15 / 8ec957745626317e39f04f8547910e353553354b` 的执行后端，属于代码依赖，不是第二个模型。缓存键补丁使用图像路径短哈希区分不同视频中的同名帧。
